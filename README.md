# ⚔️ Disciples II Tactical Battle Arena (Feature Branch: `disciples-game`)

Тактична покрокова бойова арена за правилами класичної **Disciples II: Dark Prophecy**.

---

## 🛡️ Бойові механіки

* **Формація 2x3**:
  * Кожна армія має два ряди: Авангард (передній ряд) та Тил (задній ряд).
  * Бійці ближнього бою (Мечники, Паладини) не можуть дістати тиловий ряд, поки живий хоч один боєць в авангарді.
  * Лучники та Маги мають вільний вибір будь-якої цілі.
* **Черга ініціативи**:
  * Порядок ходів визначається швидкістю (Initiative) кожного юніта.
  * Активний боєць підсвічується золотим сяйвом, доступні цілі — червоним або зеленим (для Цілителя).
* **Класи бійців**:
  * **Воїн / Танк**: Високе HP, броня, удари по передньому ряду.
  * **Лучник / Маг**: Дистанційна шкода по будь-якому ворогу.
  * **Цілитель**: Підтримка та відновлення здоров'я союзників.

---

## 🛠️ Стек та інфраструктура

* **Frontend**: HTML5 Canvas / Dark Gothic UI з клікабельним вибором цілей.
* **Backend**: FastAPI з бойовим лічильником `battle_engine_attacks_total`.
* **Reverse Proxy**: Nginx (роздача клієнта та проксування `/battle/attack`).
* **Моніторинг**: Вбудований Prometheus instrumentator.
