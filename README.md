# 🧭 Alonar RPG Engine (Feature Branch: `alonar-game`)

Покрокова браузерна рогалик-RPG, натхненна механіками **Alonar**. Проєкт побудований на модульній архітектурі з контейнеризацією через Docker, шлюзом Nginx та метриками Prometheus.

---

## 🎮 Ігрові механіки

* **Характеристики та розрахунки (`app/calculator.py`)**:
  * Первинні атрибути: Сила (STR), Спритність (AGI), Інтелект (INT), Витривалість (VIT).
  * Похідні стати: Максимальне HP/Mana, Фізична та Магічна атака, Броня, Шанс криту, Шанс ухилення.
* **Система спорядження (`app/routers/character.py`)**:
  * Слоти: Зброя, Броня, Шолом, Перстень.
  * Грейди предметів: Звичайний (Common), Зачарований (Magic), Рідкісний (Rare).
  * Динамічний перерахунок параметрів під час екіпірування.
* **Дослідження підземелля (`app/routers/dungeon.py`)**:
  * Процедурна генерація поверхів і кімнат (`app/generator.py`).
  * Типи подій: Бій із мобом, Таємнича скриня з лутом, Табір відпочинку, Бій із Босом.
  * Покроковий обмін ударами з розрахунком броні та відніманням HP.

---

## 🏛️ Модульна архітектура бекенду

```text
app/
├── routers/
│   ├── character.py   # Роути керування статами та екіпом
│   └── dungeon.py     # Роути підземелля, генерації та бою
├── calculator.py      # Математичний рушій формул RPG
├── generator.py       # Процедурний спавнер кімнат та луту
├── models.py          # Pydantic моделі даних
└── state.py           # Збереження сесії в пам'яті
main.py                # Точка входу FastAPI, підключення роутерів
static/index.html      # Інтерактивний UI гри
nginx.conf             # Маршрутизація статичного фронтенду та API
